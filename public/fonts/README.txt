FONT: drop the Bobby Jones font files here, named exactly:

  BobbyJones.woff2   (best: smallest, loads fastest)
  BobbyJones.woff    (optional)
  BobbyJones.ttf     (or .otf - fine if you only have this one)

The game tries them in that order and falls back to another handwriting-style font
until one is found. Bobby Jones is a commercial font, so make sure your license allows
using it on a website ("web font" license).
