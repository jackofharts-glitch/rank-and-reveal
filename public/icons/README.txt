PICTURES: drop PNG files here (transparent background works best, roughly 256x256 or larger,
square or close to it). The game uses a picture automatically when its file exists, and an
emoji until then. File names (all lowercase, .png):

  trophy      big trophy on the final screen
  gold        1st place medal
  silver      2nd place medal
  bronze      3rd place medal
  thinking    waiting while someone ranks
  lock        locked in (ranker and guessers)
  eyes        joined mid-turn (still an emoji - no picture yet)
  crown       host marker in the lobby
  sound_on    sound button (on)
  sound_off   sound button (muted)
  mind_reader award: guessed the most right
  open_book   award: easiest to read
  mysterious  award: hardest to read
  friends     award: knew each other best
