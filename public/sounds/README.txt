SOUNDS: drop .mp3 files here (mp3 works on every phone; .aif does NOT work in most browsers).
The game uses a file automatically when it exists, and a built-in beep until then.
File names (all lowercase, .mp3):

  drum        drumroll before each card is revealed (the end of the file lands on the reveal)
  drum_long   the long drumroll before the winner is announced (end of file lands on the reveal)
  ding        a card flips / each place is announced on the podium
  good        a guess was right
  bad         a guess was wrong
  sad         nobody got it right, and when last place is announced
  fanfare     a guesser went 5/5, or everybody got a card right
  win         the winner is revealed (first place)
  tick        small click (placing cards, + / - buttons)       [not supplied yet]
  lock        "Lock in" pressed                                [not supplied yet]
